# Game Narrative Requirement Contract

For every mission, quest, or interactive story unit, connect authored intent to
player action and runtime evidence.

| Requirement field | Required content |
|---|---|
| Player verbs | Actions the player can take and the story assumes |
| Conflict and stakes | Opposing goals, escalation, consequence and fairness |
| Character contract | Want, belief, capability, relationship, action and change |
| Story state | Stable ID, entry/exit predicates, branch, convergence, persistence and recovery |
| Delivery | Dialogue, animation, environment, audio, UI, systemic event, interruption and fallback |
| Cross-discipline owner | Narrative, design, engineering, art, audio, localisation and QA |
| Acceptance | Comprehension, agency, pacing, accessibility, localisation and failed-path evidence |

Test a normal path, branch/rejoin, failure/retry, save/load, audio-off and
localisation-expansion scenario. Reject emotional claims without an observable
oracle. A prose-complete narrative is not a satisfied software requirement.
