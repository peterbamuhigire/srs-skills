# Game architecture viewpoints

Map Ads, Analytics, crash, social, payments and other SDKs separately by purpose, audience/territory, data, consent, deletion, offline/no-fill/error behaviour, dependency direction, feature flag and kill switch. Child/privacy uncertainty keeps the integration disabled.

For shared platform reuse, record capability contract, consuming games, optionality, version/migration, performance/storage/network cost, identity boundary, fallback and removal plan. Reuse governance and packages; do not make unrelated games carry unused complexity.
