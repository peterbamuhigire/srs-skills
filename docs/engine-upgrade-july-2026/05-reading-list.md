# Recommended Books and Reading Material

## Must Encode Now

| Title | Author/issuer | Gap filled |
| --- | --- | --- |
| IEEE 29148:2018 Systems and software engineering - Life cycle processes - Requirements engineering | IEEE | Authoritative requirements quality, structure, and validation baseline. |
| IEEE 1012-2016 Standard for System, Software, and Hardware Verification and Validation | IEEE | V&V planning, independence, anomaly handling, and evidence standards. |
| Software Requirements, 3rd ed. | Karl Wiegers and Joy Beatty | Practical elicitation, analysis, quality attributes, and requirements management depth. |
| Writing Software Requirements Specifications | Andrew Stellman and Jennifer Greene | Concrete SRS craft and stakeholder-facing clarity. |
| The Software Requirements Memory Jogger | Ellen Gottesdiener | Lightweight checklists for facilitation and requirements review. |
