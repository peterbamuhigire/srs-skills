# 12-SaaS-Trust-Center-Document-Pack Skill

## Objective

Generate the buyer-facing trust pack: security overview, attestations, sub-processors, DPA, vulnerability disclosure, status page, data handling summary.

## Execution Steps

1. Verify Compliance_Docs.md, Data_Isolation_Evidence_Pack.md, Risk_Assessment.md exist.
2. Invoke `logic.prompt`.
3. Review with Security, Compliance, Legal, and Marketing leads.

## Standards

- SOC 2 / ISO 27001 / 27017 / 27018
- GDPR / POPIA / DPPA
- CSA CAIQ / SIG
