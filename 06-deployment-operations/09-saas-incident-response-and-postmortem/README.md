# 09-SaaS-Incident-Response-and-Postmortem Skill

## Objective

Generate the SaaS-tuned Incident Response & Postmortem pack: two-dimensional severity matrix (severity × tenant scope), per-severity customer-comms templates, status-page protocol, blameless postmortem template, action-item tracking.

## Execution Steps

1. Verify inputs exist.
2. Invoke `logic.prompt`.
3. Review with SRE lead and Customer Success.

## Standards

- Google SRE (blameless postmortems)
- NIST SP 800-61 (adapted for customer reporting)
