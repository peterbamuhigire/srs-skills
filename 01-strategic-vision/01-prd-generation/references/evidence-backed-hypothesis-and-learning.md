# Evidence-Backed Hypothesis and Learning

This reference is a self-contained synthesis prepared from Alexio Cassani,
*Code Revealed*, and Stephanie Diamond, *Claude For Dummies*. Use it to make a
PRD testable without turning a book into a requirement source.

## PRD learning contract

For each material product decision, record:

| Field | Required content |
|---|---|
| Problem | Named user, observed situation, and consequence |
| Hypothesis | What change is expected to improve which outcome and why |
| Evidence | Source, observation, baseline, uncertainty, and date |
| Experiment | Smallest reversible test, audience, duration, and guardrails |
| Measure | Behavioural outcome, quality threshold, and failure signal |
| Decision | Continue, adapt, stop, or gather evidence; include the countercase |

Separate discovery evidence from generated ideas. AI may help structure options,
but it cannot turn an unverified assumption into user research or market proof.

## Quality gate

Reject a feature statement that has no named user, measurable outcome, evidence
route, or stop condition. If context is insufficient, ask the smallest question
that changes the decision rather than expanding the prose.
