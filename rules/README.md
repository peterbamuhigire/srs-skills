# Rules

Always-on principles for this engine, separate from the on-demand `SKILL.md`
playbooks. See `skills-web-dev/rules/README.md` for the full rationale behind
this split (skills are the "how", rules are the checkable "what"); this file is
the short, engine-local version.

A rule belongs here only if it is checkable in one sentence and applies
regardless of which SRS phase or project is active. Everything else — waterfall
vs agile methodology choice, template structure, phase-specific checklists —
stays in the relevant `SKILL.md`.

See `rules/common/core.md` and `rules/common/phase-handoff.md`.
