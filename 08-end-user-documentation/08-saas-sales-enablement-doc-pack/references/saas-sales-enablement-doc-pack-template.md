## Discovery_Meeting_Script.md

```
1. Prepare — review CRM, recent news, trigger events.
2. Open — friendly, set time, confirm participants.
3. ACE — Acknowledge their context; Connect to your experience; Empathise.
4. Agenda — propose 3 items, ask if they would add.
5. Diagnose (S + P questions, customer-specific):
   S1 — Situation: how many <unit>? what tools today?
   S2 — Situation: roles involved? volume?
   P1 — Pain: what's the challenge with the current state?
   P2 — Pain: how does that show up week-to-week?
6. Summarize — repeat tone words, confirm understanding.
7. 3rd-party reference — share a relevant customer story (named, with permission).
8. Impact (I questions):
   I1 — What's the cost of leaving this as-is for 6 months?
   I2 — What changes for your team if this is solved?
   I3 — What does success look like in 90 days?
End: agree next step (demo / commit / go-dark response).
```

## Demo_Script.md

```
# Demo: <product line>
Length: 30 min (solution) | 60 min (consultative)

Part 1 — Demonstrate (≤ 20 min)
- Beat 1: <pain → feature → outcome>
- Beat 2: <pain → feature → outcome>
- Beat 3: <pain → feature → outcome>
- Optional Beat 4 (deep-dive on demand).

Part 2 — Integrate (≤ 10 min)
- Tie each beat back to a stated pain from discovery.
- Quantify impact using the Value Quantification Worksheet.
- End with a stated next step (mutual action plan).
```

## Closing_Playbook.md

```
Signals
- Trade: they ask for a concession in exchange for movement → respond by trading commitment.
- Commit: they propose a path → confirm in writing within 1 BD.
- Go Dark: 7 days no response → re-engage with insight, then exit if 14 days.

MEDDIC checklist
- Metrics: quantified business outcome.
- Economic buyer: identified, met.
- Decision criteria: documented and agreed.
- Decision process: mapped (steps, dates).
- Identify pain: agreed in writing.
- Champion: identified, supplied with collateral.

Mutual action plan (MAP) template:
| Step | Owner | Date | Status |

Procurement / legal / security review:
- Send security pack proactively at MEDDIC C-stage.
- Legal review of MSA: anticipate 2 redline cycles for mid-market, 3-4 for enterprise.
- DPA standard form attached.
```
