# SaaS Value Quantification Worksheet

Used in sales discovery and customer-success expansion plays. Source: Winning by Design AE method (Cost / Experience / Revenue impact).

## Impact rubric

|  | Reduce | Improve | Increase |
|---|--------|---------|----------|
| **Cost** | Reduce <cost item> by <amount> | Improve <cost efficiency> by <%> | (n/a) |
| **Experience** | Reduce <friction / time / error> by <amount> | Improve <experience metric> by <%> | (n/a) |
| **Revenue** | (n/a) | Improve <conversion / retention> by <%> | Increase <revenue stream> by <amount> |

## Quantification template

```
Customer: <name>
Discovery date: <YYYY-MM-DD>
Champion: <name>
Economic buyer: <name>

Pain identified:
1.

Today's cost / lost value:
- Quantified: $<amount> / month  (assumption: <stated>)
- Source of estimate: <interview | benchmark | internal data>

Future state with our product:
- Cost reduction: $<amount> / month
- Experience improvement: <metric improvement>
- Revenue uplift: $<amount> / month

Total annualised value: $<amount> / year

Investment (our pricing): $<amount> / year

ROI: <x>×
Payback: <months>

Caveats / assumptions to validate:
1.

Co-signed by champion (initials, date): _____ ____
```

## Use in artefacts

- Discovery summary email.
- Demo Part 2 (Integrate) — every demo beat ties to a number here.
- Mutual Action Plan — value statement at top.
- QBR — actual vs forecast value delivered.
- Renewal narrative — value realised in last cycle.
