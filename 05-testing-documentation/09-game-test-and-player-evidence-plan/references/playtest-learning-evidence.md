# Playtest Learning Evidence

Each playable slice needs one learning question and a comparable baseline.

| Evidence class | Example measure | Required control |
|---|---|---|
| Comprehension | Objective recall, route choice, task completion | Do not substitute “felt clear” for observed behaviour |
| Agency | Choice recognition and consequence expectation | Test branch, rejoin and failure recovery |
| Pacing/emotion | Session timing, drop-off, interview or coded observation | Separate preference from correctness |
| Fairness | Reaction, information access, difficulty and AI predictability | Include adversarial and accessibility cases |
| Craft/continuity | Narrative state, audio/animation, placeholder and localisation defects | Use stable build, seed, content revision and trace |

Retain failed paths and participant/context limitations. Change one causal
variable per cycle, rerun the same slice, and standardise only after the target
measure improves without a guardrail regression.
